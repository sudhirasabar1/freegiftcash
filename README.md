# GiftCash Neon Landing Page

Responsive static site with an original dark-navy and electric-blue neon theme inspired by your reference.

## Upload to GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, `privacy.html`, and `disclosure.html` to the root of your `giftcash` repository.
2. Commit changes.
3. Go to **Settings → Pages**; select **Deploy from a branch**, `main`, and `/(root)`, then Save.
4. Open the Pages URL and test the site on mobile and desktop.

## Before promoting
- The partner link `https://trckapp.org/cl/i/5n76p1` is the URL you supplied. Confirm it is the correct, active content locker URL in your account.
- Confirm the offer allows Instagram traffic.
- Rewards, eligibility, and availability are not guaranteed.
- Replace the starter privacy notice with a complete policy that matches your actual practices.
- This is a static informational website; it does not verify live offers or process payments.
